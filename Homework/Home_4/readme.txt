Сначала я создал абстрактный класс Participant в котором указал характеристики которые есть абсолютно у всех устников, id name speed в конструкторе и методы Move и GetInfo который выводит информацию об участнике ну точнее строчку возвращает. Потом как интерфейсы взял способность плавать летать и говорить. потом начал создавать классы для участников, везде наследовал Participant и добавлял интерфейсы которые соответствуют участнику, добавлял переменные которые нехватали классу, например наличие ног или интеллекта, узнал что есть такая штука как base которая ссылается на родителя и с помощью него дописывал конструктор у каждого класса и с помощью override переписывал методы. С каждым классом примерно одинаковая работа, как таковой иерархии не получилось потому что у каждого участника что то есть а чего то нету и мне показалось самым лучшим просто создать один класс и интерфейсы и их наследовать и присваивать. В мейне я создал список где задал по участнику из каждого класса. Пробегом по списку вывел информацию про всех участников, узнал про существование проверки типа с извлечением в переменную и с помощью этой штуки выводил методы интерфейсов у участников которых они есть.
